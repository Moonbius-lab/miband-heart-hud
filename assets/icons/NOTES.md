# 图标来源

`ic_fluent_heart_24_filled.svg`、`ic_fluent_heart_20_regular.svg`

- 出处：**Fluent UI System Icons**（微软官方图标库）
  https://github.com/microsoft/fluentui-system-icons
- 许可：MIT License
- 用途：本项目的爱心图标（弹窗左上角、任务栏组件、托盘图标）。
  使用时把 SVG 里的 `fill="#212121"` 替换成需要的颜色再渲染，
  所以同一个文件可以出任意颜色的图标。

选这套图标的原因：它和 FluentFlyout 用的图标体系同源（Fluent 2 / Segoe Fluent Icons），
放在一起风格一致。
